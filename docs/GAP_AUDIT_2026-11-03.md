## 四、验收脚本盲区

`npm test` = `test-tail-sales` + `test-v011` + `test-keypad-3d` + `check-roadmap` → **全部 PASS（27/27 roadmap）**。

| 脚本证明的 | 脚本**不**证明的 |
|------------|------------------|
| sellTail 月入账、生命周期月数、ledger 标签字符串 | 玩家是否「感觉卖了两年」的 UI 节奏 |
| screenOS 源码含 anticipation 等词 | 发布会帧是否真有重量/余韵（无截图/无像素断言） |
| phone3d 含「半宽」「buildKeypadPhone」「SOS」等 | 舞台上比例、材质、与厚直板并排可辨度；**liveScreen 贴皮** |

| `ui.includes('累计利润')` 类检查 | 文案是否时代正确、有无现代词漏进按键路径 |
| wow 新颖×完成度函数存在 | 数值手感、推荐线是否 <80 媒体分 |

**结论：** 当前门禁是 **API/字符串/分支存在性回归**，不是 **时代一致性 / 视觉质量 / 价感** 门禁。ERA M1「黑名单 + 截图巡检」未落地，故「脚本全绿 + 正式站可玩」仍可与「功能机发布会出戏」并存。
