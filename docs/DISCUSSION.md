# 《留学模拟器》待讨论问题清单

> 用途：方便一起拍板。每题给 2～3 个可选方向；选定后请在 Issue / 回复中标注「选 A/B/C」，设计文档将回写锁定。  
> 关联：[GAME_DESIGN.md](./GAME_DESIGN.md)

---

## Q1. 发行形态：单机 vs 带轻社区

- **A. 纯单机**：本地存档 + 结局图鉴；最简单，适合先验证玩法。  
- **B. 单机 + 可选分享**：通关后生成「录取结果卡 / 人生分支卡」可分享图或短链，无强社交。  
- **C. 含社区墙**：匿名或昵称贴结局与「血泪教训」，需审核与合规成本。

**倾向建议（可改）**：MVP 走 A，预留 B 的分享卡数据结构。

---

## Q2. 呈现形态：视觉小说 vs UI 经营面板

- **A. 偏视觉小说**：立绘 + 对话框为主，资源面板为辅；叙事沉浸强，策略可读性弱一点。  
- **B. 偏 UI 经营面板**：日程/槽位/情报看板为主，事件以弹窗卡牌插入；策略清晰，开发可控。  
- **C. 混合**：养成季偏面板，申请季关键事件与文书编辑器「小说感」加强。

**倾向建议**：B 或 C；与「Papers × Sims × 事件卡」定位更贴。

---

## Q3. 目标平台

- **A. Web（浏览器）**：分发快、便于一起试玩讨论；适合 UI 面板向。  
- **B. Steam（PC）**：付费与长内容更自然；需安装包与商店页。  
- **C. 移动（iOS/Android）**：碎片回合友好，但复杂情报 UI 需大改。

**倾向建议**：原型先 A；商业化再评估 B/C。

---

## Q4. 是否使用真实校名 / 项目名

- **A. 全部虚构院校**：合规风险低，可用夸张梗；代入感稍弱。  
- **B. 真实校名（或可识别化名）**：代入强；需商标/名誉/误导风险评审，且「评审口味」易引发争议。  
- **C. 层级标签制**：用「T0 研究型 / 文理学院 / 职业向硕」等抽象档位 + 可选玩家自定义校名。

**倾向建议**：MVP 用 C；是否上真实名放到商业化前单独决策。

---

## Q5. 幽默与扎心尺度

- **A. 温和自嘲**：家庭期望、DDL、同辈压力点到为止，少黑中介/政策。  
- **B. 轻讽刺现实主义（推荐基调）**：可嘲讽话术与信息噪音，不嘲讽玩家出身与创伤。  
- **C. 偏黑色幽默**：允许更刺的结局与系统惩罚；需年龄分级与内容警告。

**倾向建议**：默认 B，个别事件可打「敏感」标签供开关。

---

## Q6. 变现模式（若对外发行）

- **A. 买断制**：一次付费解锁完整一季 + 图鉴。  
- **B. 免费 + 章节 / 外观 DLC**：核心循环免费，第二章或额外起点包付费。  
- **C. 订阅 / 赛季事件**：不推荐作为 MVP；与单机叙事节奏冲突。

**倾向建议**：先不绑变现；文档层预留 A/B。

---

## Q7. 开局深度：角色创建复杂度

- **A. 少量预设起源卡**：快速开玩，重玩换卡。  
- **B. 中度创建**：家庭资源、起点年级、目标国/专业、一项「性格缺陷」。  
- **C. 重度模拟人生式创建**：过深，易拖慢第一小时乐趣。

**倾向建议**：MVP 用 A+可微调的 B（滑条不要超过 4～5 个）。

---

## Q8. 战斗感来自哪里？（难度哲学）

- **A. 资源饥饿**：AP 永远不够，强调取舍。  
- **B. 信息迷雾**：资源尚可，但假情报与隐藏口味是主威胁。  
- **C. 双轴**：前期偏 A，申请季偏 B。

**倾向建议**：C，与卖点「信息战 + 档案一致性」一致。

---

## Q9. 文书玩法怎么做才不无聊

- **A. 抽象：选主题标签 + 素材卡组合**，自动生成一致性检定。  
- **B. 半写作：从句库拼段落**，玩家感到「在写」但不真写作文。  
- **C. 真·自由文本**：AI 或规则评分——趣味高、成本与公平性风险高。

**倾向建议**：MVP 用 A，实验 B；暂不做 C。

---

## Q10. 是否包含「中介 / 顾问」作为可雇佣系统

- **A. 事件与情报来源即可**，不做成长期雇佣。  
- **B. 可雇佣：付费换 AP 效率 / 文书润色 / 校单建议**，但带偏差与锁定风险。  
- **C. 多顾问竞争**：不同顾问口味冲突——内容量大。

**倾向建议**：MVP 用 A，挖坑 B 为系统扩展。

---

## Q11. 多周目与解锁

- **A. 仅自由重开**，无解锁。  
- **B. 解锁新起源、事件卡注释、评审口味图鉴**。  
- **C. 新周目修正规则（如「情报更噪」挑战模式）**。

**倾向建议**：B 作为重玩诱饵；C 可选。

---

## Q12. 语言与文化版本

- **A. 先做简体中文完整版**（当前文档默认）。  
- **B. 中英双语文案同步**——成本高，适合确定商业化后。  
- **C. 先中文，预留 i18n 键名**，不承诺同步更新。

**倾向建议**：A + 工程上顺手做 C。
