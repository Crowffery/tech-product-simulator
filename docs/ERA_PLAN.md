# v0.12 · 时代一致性（功能机 / 老年机时代）开发文档

> 基线：`main` @ `1e9c602`（v0.11 已上线：开罗式形态时间轴、贷款、天使奇遇）。
> 依据：`ROADMAP.md` 中 v0.11「越早期越老」与 v0.12+「功能机 / 老年机」。
> 目标：早期形态不只是「换了个名字」——从配置、外观、发布会、舆论、市场到场景，全部回到那个年代；质量与现代手机线一致。
> 本文档只做**问题清单与方案规划**，未改代码。

---

## 一、审计方法

1. 拉取全部分支，确认 `main` 是推荐的最新版本（v0.11，含 `ROADMAP.md`）。
2. 用无头浏览器从开局完整玩两局：**老年机**一局、**功能机**一局，从企划到首月战报逐屏截图（含发布会逐帧）。
3. 逐个模块检查代码：哪些地方读了形态 / 年代（`formFactor`、`eraOfMonth`），哪些没读。

审计截图：`docs/era-audit/`（老年机设计台与供应链、功能机研发到战报、功能机发布会逐帧）。

**结论一句话：** 目前只有 `forms.js`（形态时间轴）、`parts.js` 的成本 / 厚度 / 上限修正、设计台的形态选择器认识「形态」；其余 **3D 外观、配置台、创新件、发布会、手机屏幕、弹幕评论、跑分、定价与竞品、像素场景、事件、教程文案**全部仍是现代智能机内容。

## 三、设计方案

### 3.1 核心思路：时代内容包（Era Pack）

不在各处写 `if (formFactor === 'elder')`，而是新增一个**时代内容包**，所有面向玩家的内容都从「当前时代」取：

```
src/game/eras.js
  ERA_PACKS = {
    feature: { … 功能机时代 },   // 功能机、老年机、早期翻盖 / 滑盖
    smart:   { … 智能机时代 },   // 厚直板、直板、阔直板（= 现在的现代内容）
    fold:    { … 折叠时代   },   // 折叠形态（沿用现代 + 折叠专属）
  }
  packOf(design | state)  // 产品的时代由「形态」决定；世界的时代由「月份」决定
```

**两个时代概念要分开：**
- **产品时代**（由形态决定）：这台机器的部件、卖点、发布会、屏幕、评论。→ 智能机时代做老年机，内容仍是老年机。
- **世界时代**（由月份决定）：行业新闻、竞品在卖什么、行业大事、价格水位。→ 智能机时代再做功能机，评论会说「都什么年代了还用按键机」，老年机则作为刚需长尾存在。

**每个内容包包含（与现代线一一对应，保证质量对等）：**

| 内容 | 现代线现状 | 功能机包要提供 |
|---|---|---|
| 部件档位（芯片 / 屏幕 / 摄像头 / 电池 / 材质 / 尺寸） | ✅ | 基带芯片 · 单色屏 / 彩屏 / 大彩屏 · 无 / 30 万 / 130 万像素 · 800 / 1000 / 1500 mAh（待机 7 / 12 / 20 天）· 工程塑料 / 烤漆 / 金属拉丝 |
| 时代专属配置 | 镜头模组、前摄开孔 | **键盘**（数字键 / 大字键 / 全键盘）、**铃声**（单音 / 16 和弦 / 64 和弦 MP3）、**制式**（GSM / GPRS / EDGE / 3G） |
| 研发槽名称 | 性能 / 屏幕与外观 / 影像 / 续航 / 系统 | 流畅度 / 外观与屏幕 / 拍照 / 待机与耐用 / 铃声与功能 |
| 定位 | 旗舰 / 主流 / 轻巧 / 专业 | 父母刚需（老年机）/ 学生入门 / 商务 / 时尚 |
| 卖点 + 兑现规则 | 极致轻薄等 6 个 | 超长待机 / 字大声大 / 一键呼救 / 砸不坏 / 双卡双待 / 和弦铃声 / 拍照手机 / 时尚翻盖 |
| 创新与实用功能池 | 45 项 | 彩屏、和弦铃声、MP3、FM 收音机、内置摄像头、蓝牙、红外、双卡双待、手电筒、翻盖、滑盖、旋转屏、手写笔、全键盘、SOS 键、超大喇叭、手机电视、跑马灯灯效（山寨梗）…约 20 项，按世界时代逐步出现 |
| 价格 / 价带 / 竞品 | ¥1999–6999 | ¥199 / ¥599 / ¥1,599 价带；竞品（虚构品牌）的同期按键机型号与价格 |
| 成本模型 | BOM ×70 + ¥250 | 独立 BOM 表（整机约 ¥150～600），利润靠走量 |
| 市场竞赛 | 芯片代差 | **网络制式代差**（2G → 2.5G → 3G），落后同样掉价掉口碑 |
| 3D 外观 | 触屏直板 / 折叠 | 直板按键机、翻盖、滑盖；老年机大按键 + SOS + 手电筒 + 挂绳孔；小屏、天线、听筒格栅 |
| 手机屏幕（发布会 / 设计台） | screenOS 现代系统 | **功能机 OS**：信号格、电量格、运营商名、九宫格菜单、短信、贪吃蛇；单色屏为绿底黑字，彩屏为低分辨率像素 |
| 外观自定义 | 壁纸 / AG / 镜圈 | 开机画面、待机图片、键盘背光颜色、挂绳颜色、机身贴纸 |
| 发布会节目单 + 产品短片 | 芯片 / 材质 / 影像 / 续航 / 快充 / 屏幕 / 轻薄 | 待机（日历翻页 + 电量格）、铃声（波形 + 和弦音符）、砸核桃 / 摔落测试、大字体对比、一键呼救演示、T9 打字、单色屏到彩屏点亮、30 万像素样张（像素风调侃） |
| 时代梗 | Are you OK / 遥遥领先… | 砸核桃、待机一个月、八个喇叭、移动联通双卡、「喂？喂？听得见吗」 |
| 弹幕 / 评论（含评论者身份） | 跑分、夜景、全面屏 | 「给我爸买一台」「铃声够响」「字终于看得清」「营业厅店员：卖得很好」 |
| 跑分 → 测试 | CPU / GPU / AI | 工程机测试：跌落、待机、通话音质、信号、按键寿命 |
| 像素场景 | 触屏直板 | 货架、研发台、量产线、机型墙换成按键机像素图 |
| 研发 / 行业事件 | 现代 | 运营商定制合约机、山寨机冲击、3G 牌照、短信资费、彩铃业务 |
| 引导 / 术语 / 结局 | 现代 | 时代版引导、术语（制式、合约机）、称号（老年机之王、待机冠军、砸不坏传说） |

### 3.2 时间轴重排（延长游玩）

目前 36 个月里早期只占 9 个月。建议：

| 时代 | 月份（建议） | 时长 | 主力形态 |
|---|---|---|---|
| 功能机时代 | 1–18 | 18 个月（约 3～4 代） | 功能机、老年机、翻盖 / 滑盖 |
| 智能机萌芽 | 19–30 | 12 个月 | 厚直板 |
| 智能机时代 | 31–48 | 18 个月 | 直板、阔直板 |
| 折叠兴起 | 49–60 | 12 个月 | 小折、阔折 |

- 一局延长到 **60 个月**（「完整编年」模式）；保留现有 36 个月「快速局」可选，从智能机萌芽开始。
- **「智能机革命」时代切换事件**：竞品发布触屏机、媒体整版报道；之后普通功能机需求逐月下滑，老年机作为刚需长尾保留（形成「转型 vs 坚守老年机」的策略选择）。
- HUD 显示世界时代名称（如「功能机时代 · 第 2 年」）。

### 3.3 防漏机制（必须做）

1. **时代用词黑名单测试**（`scripts/test-era-lint.mjs`）：用功能机包生成整局所有面向玩家的文本（配置台、卖点、发布会节目单、弹幕、评论、事件、引导），扫描「跑分 / 全面屏 / 高刷 / 夜景 / 大底 / 快充 W / AI / 5G / 钛 / 折叠 / 遥遥领先 / Are you OK…」，命中即失败。
2. **截图验收脚本**：自动玩一局功能机、一局老年机，逐屏截图（含发布会逐帧），人工对照本清单逐项打勾。
3. 所有内容消费方统一走 `packOf()`，代码评审时检查是否还有直接读现代表（`PARTS` / `SELL_POINTS` / `APP_DEFS`）的地方。
