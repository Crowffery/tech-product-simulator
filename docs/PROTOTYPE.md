# 原型说明（浏览器可玩）

> 《电子产品发展国》最小可玩切片 · 对齐 [MVP.md](./MVP.md)

## 怎么玩

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173/`）。  
生产构建：`npm run build` → 静态文件在 `dist/`，可用 `npm run preview` 预览。

**试玩路径：** 新开一局 → 起公司名 → 招聘并分派 → 企划手机 → 选供应商 → 按月给研发槽加点（可能抽事件）→ 备货 → 发布会准备/选项 → 媒体分 → 首月销量 → 规划下一代或重开。右上角可存档（`localStorage`）。

## 外观台 Demo（V5 先行验证）

入口：标题页「🎨 外观台 Demo」，或直接打开 `/studio.html`。独立页面，不影响主游戏存档。

- **配置台**：定位 + 芯片 / 屏幕 / 主摄 / 电池 / 材质 / 尺寸 档位；实时厚度、重量、蜂鸟实验室跑分、单台成本与建议价带；研发槽上限条；卖点承诺 ✓/✗  
- **外观台**：圆角、屏幕形态、7 种镜头布局、16 色板 + 自定义、纯色 / 边框撞色 / 上下拼色、机型名与公司名  
- **像素化 3D**：three.js 参数化机型（无美术建模），低分辨率渲染 + 减色 + Bayer 抖动 + 深度描边；像素度 ×2 / ×3 / ×4 / 关 可切换对比；拖拽旋转、预设视角、闲置自转  
- **年度新闻**：每次打开随机流行色 + 流行模组（🔥 标记），命中加外观分  
- **外观分**：底子（材质+屏幕上限）、材质 × 定位、趋势、屏幕形态、厚重超标；对比上一代给「延续 / 小改 / 大改」标签  
- **发布会揭幕**：灯暗 → 聚光 → 升起旋转 → 弹幕 + 彩纸 → 外观分卡  
- **历代机型馆**：入馆截图缩略图，点击载入；「沿用上代」自动 +1 代号  
- 代码：`studio.html` → `src/studio/main.js`（UI）、`parts.js`（数据与计分，纯函数）、`phone3d.js`（three.js，动态 import）  
- 存储键：`epdg-studio-draft`、`epdg-studio-museum`（localStorage，读写失败时静默）

## 交互（少点击）

- 标题页突出「继续游戏」；操作自动存档
- 组队 / 企划 / 供应链均有 **采用推荐 → 下一步**；高级选项折叠
- 研发默认 **一键均衡推进**；事件 **一键稳妥处理**
- 供应商+备货同屏；发布会改为 **3 个大策略按钮** 直接出分
- 可「跳过动画」；默认短动画

## 视觉（开罗味改版）

- 左侧 **像素办公室** canvas：工位、显示器闪烁、职员走动/敲键盘/欢呼
- 右侧 **厚边框指令面板** + 开发ゲージ；职员像素脸 + 星级
- 事件 / 发布会 / 媒体分为 **弹窗揭晓**（大数字动画）；月推进有「半个月过去了」闪字
- 音效目前为静音占位文案，优先动画与节奏感

## 技术

- Vite 5 + 原生 ES Module（无 React、无后端、无付费 API）；外观台额外使用 three.js（约 135 KB gzip，按需加载）
- 入口：`index.html` → `src/main.js` → `src/ui.js` + `src/game/*`
- 存档键：`epdg-prototype-v1`

## 与设计 v0.6（GAME_DESIGN §3.4）的差距

原型仍是 v0.5 的数值模型，以下是 **V4 决策深度** 要改的地方：

| 现状 | 问题 | v0.6 目标 |
|------|------|-----------|
| 体验分 = 槽位平均进度 | 研发怎么分都差不多 | 研发量 × 匹配度（定位理想配比） |
| 卖点只给少量加成 | 卖点是装饰 | 卖点绑定槽位，不达标扣分 |
| 高价带利润约为主流的 2 倍 | 永远选最高价 | 价格 × 定位联动、需求曲线 |
| 延期只多付一个月工资 | 时间没有代价 | 档期、趋势、1 家竞品 |
| 发布会「惊喜彩蛋」期望值最高 | 固定最优解 | 风格 × 卖点匹配，翻车率看稳定度 |
| 媒体分是绝对分 | 每代一样 | 相对期望线 |
| 只结算首月 | 世代之间断开 | 长尾销量 + 轻蚕食 |
| 推荐接近最优 | 推荐替玩家玩 | 推荐 = 稳但平庸 |
| 无终点 | 缺长期目标 | 3 年短局 + 结局称号 |
| 无产品外观 / 配置 | 做完只看分，缺「欣赏自己产品」 | V5：配置台 + 外观台 + 像素化 3D（§4.8）——**独立 Demo 已做**，尚未接入主循环 |

## 虚构品牌

默认随机公司名均为虚构（如「键程实验室」「北桥电子」），**不**使用真实消费电子商标。
