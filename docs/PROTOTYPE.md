# 原型说明（浏览器可玩）

> 《电子产品发展国》最小可玩切片 · 对齐 [MVP.md](./MVP.md)

## 怎么玩

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173/`）。  
生产构建：`npm run build` → 静态文件在 `dist/`，可用 `npm run preview` 预览。

**试玩路径（v0.9）：** 新开一局 → 起名 → 📋 企划 → 🎨 设计（3D：配置 / 创新 / 外观）→ 🤝 供应链 → 🔬 研发（推进 / 一直推进，偶发事件）→ 🏭 量产 → 🎤 发布会（全屏 3D 演出）→ 📰 评分 → 🛒 首月销量 → 🏛 规划下一代（部门升级）→ 下一代。自动存档（`localStorage`，键 `epdg-prototype-v2`）。

## 主流程（v0.9，竖屏优先）

- 布局：HUD → 阶段进度条 → 像素场景 → 操作面板 → 吸底主按钮；桌面端居中成手机宽度的一列，设计阶段放宽
- 场景（`src/scenes.js`，240×150 逻辑像素）：车库标题、会议室、供应商码头、研发实验室（5 工位 + 事故变体）、量产工厂、发布会后台、舞台定格、门店（缺货 / 正常 / 积压）、年会机型墙、倒闭
- 部门（`DEPTS`）代替招聘；研发点每次发布结算，在设计阶段「💡 创新」页解锁概念件
- 逻辑：`src/game/logic.js`（流程、部门、研发上限、惊艳度、出圈度、销量）；UI：`src/ui.js`
- V4 数值（`src/game/market.js`）：理想配比与匹配度、企划笔记、卖点承诺、价格 × 定位、档期日历、竞品撞档、期望线、3 年结局称号；研发可「提前量产」
- 场景彩蛋：会议室电视播竞品快讯、实验室撞档时贴出竞品海报、橘猫偶尔溜过、码头和门店按月份下雨 / 下雪、结局年会放烟花

## 设计沙盒（外观台 Demo）

入口：标题页「🎨 设计沙盒」，或直接打开 `/studio.html`。独立页面，25 个概念件全部解锁、每代最多 3 个，不影响主游戏存档；同一组件也是游戏内的设计阶段（`src/studio/studio.js`）。

**玩法**
- **配置台**：定位 + 芯片 / 屏幕 / 主摄 / 电池 / 材质 / 尺寸 档位；实时厚度、重量、蜂鸟实验室跑分、单台成本与建议价带（数字滚动 + 增减浮字）；研发槽上限条；卖点承诺 ✓/✗  
- **悬停预览**：鼠标停在档位上，直接显示「厚 +1.1mm · 重 +33g · 成本 +140 · 续航 +20」  
- **外观台**：圆角、屏幕形态、7 种镜头布局、16 色板 + 自定义、纯色 / 边框撞色 / 上下拼色、机型名与公司名  
- **拆解爆炸图**：后盖 / 内部元件 / 中框 / 前屏分层飞开，露出主板、芯片（S5 带铜色均热板）、电池（容量标签）、影像传感器、扬声器、排线；两侧标注 + 引线  
- **年度新闻**：随机流行色 + 流行模组（🔥），命中加外观分  
- **发布会揭幕**（约 5 秒）：暗场 → LED 大屏 COMING SOON + 鼓点 → 光柱扫动、机型从底座下旋转升起 → 白闪 + 爆音 + 号角 + 掌声 → LED 打出机型名、观众举手机、闪光灯咔嚓、弹幕、彩纸 → 外观分滚动 + 评级盖章  
- **历代机型馆**：入馆截图，Gen 编号，点击载入；「沿用上代」自动 +1 代号并给「延续设计语言」标签  

**创新层（v0.8，对应 GAME_DESIGN §3.5）**
- **💡 创新页**：8 个概念件（透明后盖、背部副屏、墨水背屏、灯效后盖、实体键盘、机械快门键、卫星天线、主动散热风扇），每代最多 2 个，带互斥、成本、上限影响，全部在 3D 上可见（风扇会转、灯带会变色、透明后盖能看到内部）  
- **品类组合**：7 种隐藏的「不该这么配」组合（如小屏旗舰、透视旗舰），首次做出即解锁  
- **惊艳度 = 新颖度 × 完成度**：对比市场记忆（自己的机型馆 + 3 家虚构竞品）；首发最值钱，下一代仍独家，再往后被竞品跟进而贬值；新工艺首发完成度 −10%，第二代 −5%  
- **大改 / 小改款**：小改锁定形体与概念件，快而稳；大改全部开放；原样小改会被判「挤牙膏」  
- **行业快讯**：竞品扎堆的红海 + 「XX 跟进了你的 YY」  
- **发布会自适应**：首发概念 / S、A 级给完整演出，其余约 2 秒快速版；随时可「跳过」  
- 配色、命名、布局样式**不计分**（取消了旧版「追流行加分」）

**画面（像素化 3D）**
- three.js 参数化机型，无美术建模；机身拆成中框环 + 后盖 + 前屏 + 内部元件四层  
- 低分辨率渲染 → 只对亮度分段（保留色相的赛璐璐感）→ 1/z 二阶差分找轮廓（同色系暗描边）→ 法线折边高光（倒角、镜头环亮边）→ 最近邻放大  
- 摄影棚软箱环境贴图（玻璃 / 金属上的反光条）、虹彩镜片、屏幕炫光、实时投影、浮尘、换件时弹性形变 + 像素火花  
- 像素度 ×2 / ×3 / ×4 / 高清 可切换  

**声音**：全部 WebAudio 现场合成的 8-bit 音效（换件、换色、拆解、鼓点、爆音、号角、掌声、快门），右上角可静音。

**代码**：`studio.html` → `src/studio/main.js`（UI）、`parts.js`（数据与计分，纯函数）、`phone3d.js`（three.js 舞台，动态 import）、`sfx.js`（音效）。存储键：`epdg-studio-draft`、`epdg-studio-museum`、`epdg-studio-mute`。

## 交互（少点击）

- 标题页突出「继续游戏」；操作自动存档
- 组队 / 企划 / 供应链均有 **采用推荐 → 下一步**；高级选项折叠
- 研发默认 **一键均衡推进**；事件 **一键稳妥处理**
- 供应商+备货同屏；发布会改为 **3 个大策略按钮** 直接出分
- 可「跳过动画」；默认短动画

## 视觉（开罗味改版）

- 左侧 **像素办公室** canvas：工位、显示器闪烁、职员走动/敲键盘/欢呼
- 右侧 **厚边框指令面板** + 开发ゲージ；职员像素脸 + 星级
- 事件 / 发布会 / 媒体分为 **弹窗揭晓**（大数字动画）；月推进有「半个月过去了」闪字
- 音效目前为静音占位文案，优先动画与节奏感

## 技术

- Vite 5 + 原生 ES Module（无 React、无后端、无付费 API）；外观台额外使用 three.js（约 135 KB gzip，按需加载）
- 入口：`index.html` → `src/main.js` → `src/ui.js` + `src/game/*`
- 存档键：`epdg-prototype-v1`

## 与设计 v0.6（GAME_DESIGN §3.4）的差距

原型仍是 v0.5 的数值模型，以下是 **V4 决策深度** 要改的地方：

| 现状 | 问题 | v0.6 目标 |
|------|------|-----------|
| 体验分 = 槽位平均进度 | 研发怎么分都差不多 | 研发量 × 匹配度（定位理想配比） |
| 卖点只给少量加成 | 卖点是装饰 | 卖点绑定槽位，不达标扣分 |
| 高价带利润约为主流的 2 倍 | 永远选最高价 | 价格 × 定位联动、需求曲线 |
| 延期只多付一个月工资 | 时间没有代价 | 档期、趋势、1 家竞品 |
| 发布会「惊喜彩蛋」期望值最高 | 固定最优解 | 风格 × 卖点匹配，翻车率看稳定度 |
| 媒体分是绝对分 | 每代一样 | 相对期望线 |
| 只结算首月 | 世代之间断开 | 长尾销量 + 轻蚕食 |
| 推荐接近最优 | 推荐替玩家玩 | 推荐 = 稳但平庸 |
| 无终点 | 缺长期目标 | 3 年短局 + 结局称号 |
| 无产品外观 / 配置 | 做完只看分，缺「欣赏自己产品」 | V5：配置台 + 外观台 + 像素化 3D（§4.8）——**独立 Demo 已做**，尚未接入主循环 |

## 虚构品牌

默认随机公司名均为虚构（如「键程实验室」「北桥电子」），**不**使用真实消费电子商标。
