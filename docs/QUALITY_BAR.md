# 质量标准与全量核验（v1.4）

> 目的：先把「惊艳」说清楚成可以检查的标准，再把五轮反馈里暴露过的每一个问题重新核一遍，确认现在是否还存在。

## 一、「惊艳」的标准（对齐用）

| # | 标准 | 怎么判断达标 |
|---|---|---|
| S1 | **每个决定都有看得见的后果** | 定位、卖点、配置、定价、备货、芯片、投资——每一项在 1～2 个界面内都能看到数字、评论或画面的变化 |
| S2 | **不重复** | 同一场里弹幕 / 评论不重样；音乐不循环同一段；事件、竞品、市场每代都有变化 |
| S3 | **策略真的不同** | 平价、主流、旗舰、芯片自研 / 外购各有成功路线，没有「无脑最优」，也没有「必死之路」（除了明显不合理的玩法） |
| S4 | **长线有目标** | 有钱之后仍有值得追求的东西：出货量排名、战略投资、芯片领先、结局称号 |
| S5 | **成品感** | 没有 Demo 字样；有正式标题画面；音乐随阶段变化；发布会有运镜和动画 |
| S6 | **全部反馈复核** | 五轮反馈逐条复核，有证据 |

## 二、本轮新增（第五轮）

| 项 | 做了什么 |
|---|---|
| 音乐重做 | 删掉循环播放的两段音频，改为**生成式音乐引擎**（WebAudio 实时合成）：7 种情绪（标题梦幻 / 办公室 lo-fi / 研发专注 / 出事紧张 / 发布会燃 / 卖爆欢快 / 倒闭落寞），随阶段自动切换；和弦进行、旋律动机、鼓组每 8 小节重新生成，偶尔转调、偶尔留白。 |
| 镜头模组与能力绑定（上轮遗留 B5） | 镜头模组移到「配置」并有成本：方形 / 圆形是大模组，放得下潜望长焦和一英寸大底；竖排胶囊、悬浮独立放不下，硬塞会让影像加成减半并提示。 |
| 平价路线的专属优势（上轮遗留） | **规模效应**：累计出货越多，采购越便宜（最多 -15%）；走量路线可以冲出货量排名。 |
| 后期花钱的地方（上轮遗留） | **战略投资**：线下体验店、进军东南亚 / 欧洲 / 北美、自建工厂、芯片设计中心——一次投入 + 每月运营费，各有解锁条件。 |
| 长线目标 | **国内出货量排名**：你和 4 家竞品按最近三个月出货量排名，每代年终会显示名次升降；结局有「市场第一」「一线品牌」「全球化」称号。 |
| 年终会分页 | 「年终复盘」（财报、排名、在售产品）和「投资与升级」两页，按注意力顺序看。 |

## 三、全量核验（五轮反馈）

验证方式：
- **构建**：`npm run build` 通过。
- **浏览器回归**（无头 Chromium）：开局 → 两代完整流程（企划 / 设计 / 供应链 / 研发 / 量产 / 定价 / 发布会 / 评分 / 战报 / 年终会 / 行业大事件）、跑分、带梗发布会、后期存档（第 3 代年终会、三年结局），全程无报错。
- **数值模拟**：游戏逻辑批量跑 3 年 × 50 局 × 13 种策略。
- **音乐**：浏览器内用分析器测 7 种情绪的输出电平。
- **文本**：脚本统计 400 场发布会的弹幕 / 评论重复。

### 第一轮：Demo 感、注意力、互动、发布会、难度

| 问题 | 现在 | 证据 |
|---|---|---|
| 开始界面不像游戏 | ✅ 不存在 | 全屏标题：动画夜景车库 + Logo + 菜单（继续经营带存档摘要 / 创立新公司 / 自由设计工坊 / 设置）+ 版本号 |

## 四、模拟结果（3 年 × 50 局）

| 策略 | 破产 | 平均现金 | 出货量最好排名 | 登顶 |
|---|---|---|---|---|
| 主流 · 激进备货 + 出海 + 自研 | 0 | ¥91 亿 | 2.0 | 20/50 |
| 旗舰堆料 + 自研 | 0 | ¥110 亿 | 4.2 | 0 |
| 主流 · 每代迭代 + 自研 | 0 | ¥91 亿 | 3.5 | 0 |
| 平价 · 激进走量 + 自研 + 出海 | 1 | ¥14.5 亿 | 3.3 | 6/49 |
| 主流 · 每代照抄 | 0 | ¥6 亿 | 5.0 | 0 |
| 主流 · 从不升级芯片 | 0 | ¥16 亿 | 4.7 | 0 |
| 平价 · 低价倾销 + 不升级芯片 | 27 | ¥2 亿 | 2.6 | 1 |
| 平价 · 塞顶级芯片卖 ¥1999 | 50 | — | — | — |

结论：利润路线（旗舰）和份额路线（主流 / 平价走量）是两种赢法；照抄、不升级芯片、倾销都明显吃亏；不合理配置必死。

## 五、仍然开放的点（需要你们试玩判断）
- 数值都是按模拟定的，真人玩会比模拟 AI 聪明，**难度可能偏低**；建议你们玩一局后告诉我「哪里太容易 / 太难」。
- 音乐是合成器音色，风格偏「复古电子 / lo-fi」；如果想要真实乐器的质感，需要另外制作音频素材。
