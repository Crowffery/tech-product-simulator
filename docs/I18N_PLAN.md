# 多语言计划（中文 / English）

## 已拍板的原则

1. **不暴露具体市场**：运营商、卖场、展会、媒体、竞品全部虚构且通用（星联通信 / 数码港 / 国际移动通信展 / 数码周刊 / 蓝莓 / 方块 / 极光 / 青橙）。不出现只属于某一国的制度或平台（如某国补贴政策名、某国电视晚会、某国社交软件）。
2. **梗跟着语言走**：同一个「梗位」（例如「发布会开场白」「芯片领先」「定价太贵」）在中文版用中文语境的梗，在英文版用英文语境的梗，不做直译。
3. **货币按语言显示**：游戏内统一存点数；中文显示 ¥（1 点 = ¥100 万），英文显示 $（约 ¥6.5 = $1，零售价取 x9 尾数）。
