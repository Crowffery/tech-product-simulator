# 不同时代的手机是怎么「上市」的：历史调研与游戏设计

> 目的：发布会阶段按时代换流程。按键时代的手机，现实里不是靠 CEO 上台讲 40 分钟来卖的。
> 原则：**游戏不暴露具体是哪个市场**——运营商、媒体、卖场、展会全部虚构且通用；梗与口吻跟随语言本地化（中文版用中文梗，英文版用英文梗）。

## 1. 调研结论（以北美市场为主要参照）

| 时期 | 新机怎么跟消费者见面 | 证据 |
|---|---|---|
| 按键时代（约 2000–2006） | **行业展会亮相**（CES、CTIA、3GSM 等）+ **新闻稿**；同一场活动一次发多款机型 | 2005 年 Nokia 在 Nokia Connection、3GSM 等活动一次发布 7 款 / 3 款新机 [1][2] |
| | **运营商独家首发**：新机先只在一家运营商卖，合约价 + 两年合约；爆款能给运营商带来新用户，独家合作因此越来越多 | RAZR V3：2004 年 7 月由 Motorola CEO 在芝加哥小型活动亮相，11 月起由 Cingular 独家首发，合约价 $500，90 天卖 75 万台，独家期 8 个多月卖 500 万台，之后各家降到 $150–200 [3][4] |
| | **电视广告、卖场和运营商门店**是主要触达方式；铃声、短信投票这类「增值业务」是营销抓手 | 2004 年起铃声销量被单独统计，2007 年见顶；运营商开设官方铃声商店 [5]；电视短信投票被视为推动手机普及的因素之一 [6] |
| | **细分人群的专门机型**走的是直营 / 邮购和合作伙伴渠道，不靠发布会 | 2006 年 Jitterbug（大按键老年机，与三星合作）以虚拟运营商形式推出，裸机约 $147 [7][8] |
| 智能机萌芽（2007） | **演讲式发布会**出现：厂商自己办主题演讲，现场演示；展会被抢走风头 | 2007 年 1 月 9 日 iPhone 在 Macworld 主题演讲发布，同期 CES 黯然失色；评论认为大型展会变得更适合谈生意而不是发新品 [9][10] |
| 智能机时代（2011 起） | 演讲式发布会成为行业标配，后来者普遍沿用（服装、PPT 风格都在模仿） | 2011 年 8 月小米首款手机发布会被普遍视为模仿乔布斯式发布会 [11] |

**结论**：按键时代的「上市」= **渠道 + 展会 + 广告**，主角是运营商和卖场，媒体是报纸杂志评测；演讲式发布会要到智能机萌芽才出现，并在智能机时代成为标配。

## 2. 游戏设计：按产品时代切换上市流程

### 2.1 按键机：「上市方案」（取代发布会）

定价之后，不再选发布会风格，而是做一份上市方案：

**① 首发渠道（选一个）**

| 方案 | 现场演出 | 经济效果 |
|---|---|---|
| 运营商独家首发 | 「联合签约仪式」：运营商代表与你同台，大屏签约、合影、首批订单数字跳出来 | 首批货由运营商包销（不压库存）；每台少赚一截（运营商要分成）；销量只覆盖一家运营商的用户，略低 |
| 通信展亮相 | 「展台」：展馆灯光、人流、展台讲解员现场演示；记者围上来拍 | 媒体分加成、话题加成；要付展位费；同场竞品多，可能被抢风头 |
| 全渠道铺货 | 「卖场开售」：卖场 / 运营商门店柜台，店员演示、排队、价签 | 正常利润、正常风险，没有额外加成 |

**② 广告投放（选一个）**

| 投放 | 现场演出 | 经济效果 |
|---|---|---|
| 不投放 | — | — |
| 报纸杂志 | 杂志内页广告 + 评测版面 | 小额费用，媒体分小幅加成 |
| 电视广告 | 30 秒电视广告（产品短片剪成广告，结尾是价签和「现已上市」） | 大额费用，销量明显加成 |

演出全部复用已有的 3D 舞台、产品短片和短信墙；按方案换「舞台布景」与「镜头语言」（电视广告用 4:3 电视框 + 扫描线；展台用展馆灯光 + 人流；签约仪式用横幅 + 合影闪光灯）。

### 2.2 智能机：演讲式发布会

保留现有发布会。编年模式中，智能机革命（第 19 月）那一刻起，「发布会」这种形式才第一次出现在游戏里——革命事件的演出本身就是竞品的第一场演讲式发布会。

## 3. 去市场化与本地化

- 虚构且通用：运营商（「星联通信」/ StarLink）、卖场（「数码港」/ GadgetMart）、展会（「国际移动通信展」/ World Mobile Expo）、杂志（「数码周刊」/ Gadget Weekly）。
- 价格以「游戏币」存储，显示时按语言换算：中文 ¥，英文 $（约 1/6，尾数 9）。
- 梗进本地化包：中文（砸核桃、遥遥领先……）/ 英文（drop test、"one more thing"……），同一个段落 id 在两种语言里各自取。
- 去掉只属于某一国的说法：预存话费送手机 → 签约送机；移动梦网 → 运营商门户；春晚广告 → 年度盛典黄金广告位；县城代理 → 小城镇代理。
