# v0.15 实测审计：文档宣称 vs 实际表现

> 审计对象：`origin/main` @ `adc768d`（feat(v0.15)）。
> 方法：Playwright 以 400×820 手机竖屏，**完整编年模式**分别用「功能机」「老年机」从开局玩到首代销售结束，逐阶段截图并导出页面全部文字；同时逐文件读代码，对照 `ERA_PLAN.md` / `TECH_PLAN.md` / `GAP_AUDIT_2026-11-03.md` 附录 C 的「✅ 已关闭」声明。
> 截图与文字导出见 `docs/era-audit/v0.15-before/`。

## 结论

`GAP_AUDIT` 附录 C 把 A–M 几乎全部标为 ✅，但实际游玩中：

- **按键机发布会根本播不下去**——节目单一开始就抛异常，舞台停在「今天，我们带来——」画面直到超时（P0-1）。
- 设计台、研发、评分、定价、发布会定制里**仍然大量出现现代内容**：跑分、芯片、Pro/Max、镜头模组、全面屏、灯效后盖、百瓦快充、AI 键、Are you OK、蓝莓 ¥6999……一次按键局的页面文字里，「跑分」16 次、「芯片」30 次、「模组」22 次、「Are you OK」18 次、「彩蛋」36 次。
- 按键机价格**被强制抬到 ¥999**（代码写死下限），老年机因此被评论「贵得离谱」。
- 产品短片（films）**合进来了但没有一个段落能真正播放**；现代发布会也一样没接上。
- 时代文案大量是开发者口吻或「现代人回看」口吻（「先定形态……避免『旗舰影像』写在老年机上」「有年代感」「实体键真香」），不是那个年代的人会说的话。

以下按严重度列出全部问题（共 64 项），每项写明**现象 → 原因 → 修复方案**。所有问题在本轮全部修复，修复后的复核结果见文末。

## 验证方法（本轮新增，防止再次「测试全绿但游戏出戏」）

1. `scripts/test-era-lint.mjs` 扩展：除数据表外，**实际调用**节目单生成、评论生成、研发评语、卖点说明、定价竞品、发布会定制选项，对生成的文字扫黑名单。
2. `scripts/audit-era.cjs`：Playwright 完整游玩按键局，导出**整页文字**扫黑名单；任何命中即失败。
3. `scripts/test-era-econ.mjs`：固定随机种子模拟按键时代 4 种策略，断言价格、单台利润、首代销量与第 18 月现金区间。
