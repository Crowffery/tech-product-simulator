# 第二轮试玩复盘（双人试玩对话整理）

> 来源：作者与朋友（数码爱好者）的一局完整试玩对话。
> 本文先把对话里的「问题 / 需求」逐条拎出来，再给出改进方案，最后逐项核对是否达标。

---

## 一、问题与需求清单

### A. 经济系统：「好评如潮却只赚 10 块」

| # | 原话（节选） | 问题本质 |
|---|---|---|
| A1 | 「钱不能这么标，29 块？你手机公司要体现钱多」 | 金额没有单位，看起来像小卖部，不像手机公司 |
| A2 | 「大家一致好评，但我只赚了 10 块钱，成本都赚不回来」 | 利润对产品好坏不敏感：首月销量被备货卡死，爆款和平庸款赚得差不多 |
| A3 | 「我第一款成功了，第二款没资金，这也太不合理了」 | 爆款的收益没有延续；钱为什么没了看不出来 |
| A4 | 「莫名其妙钱就没了，跟销量无关，体现不出来」 | 现金流不透明：工资、事件、旧款回款没有账本 |
| A5 | 「苹果那时 5000 块也爆了，因为极致性能和创新」「诺基亚和苹果都能出爆款」 | 高价 + 强创新应该也能卖爆；平价和高端是两个都能成功的市场 |
| A6 | 「如果一下赚很多就没难度了…无脑堆性能」「开罗就是用意外事件去打破平衡」 | 赚钱可以多，但难度要来自别处：意外事件、竞争、成本、物理约束 |

### B. 真实感与专业度（数码人视角）

| # | 原话（节选） | 问题本质 |
|---|---|---|
| B1 | 「成本 3000 多？那旗舰个鬼」「1999 的旗舰芯片？这也太奇怪了」 | 部件成本不真实：顶级芯片的手机能卖 1999 还赚钱 |
| B2 | 「机械快门键…不专业，叫 AI 拍照按键 / 相机控制键」 | 部件命名和说明不专业 |
| B3 | 「金属分很多种：铝、钛…钛贵但散热不如铝」「素皮也有好几种」 | 材质太粗：同一材质下应有子类，成本/重量/散热不同 |
| B4 | 「前置摄像头是硬件要加成本，谁跟你放外观？」 | 影响成本的选项（屏幕开孔形态）放在「外观」里，分类不对 |
| B5 | 「圆形和方形镜头模组不一样…潜望长焦」 | 镜头模组造型是否影响成本、语义不清 |
| B6 | 「这叫创新？」（耳机孔、红外、存储卡出现在「创新」里） | 常规功能和前沿创新混在一起 |

| B8 | 「白色手机正面不白，侧面才应该灰」 | 3D 光照让浅色机身发灰，颜色还原差 |

### C. 规则理解与说明

| # | 原话（节选） | 问题本质 |
|---|---|---|

## 二、方向判断（D3）

两个方向不冲突，按「开罗式经营为主、外观是可选的乐趣层」处理：

- **主线 = 经营**：每代关键决策只有几个（定位、卖点、配置取舍、定价、备货），每个都有清楚的代价，成品在发布会上展示。
- **外观 = 可选的换装层**：想玩的人自由度要够（拼色方向、自定义色、镜头造型），不想玩的人一键推荐就能走。
- **影响成本的东西都归「配置」**，「外观」只放不花钱的东西——这样两种玩家都不会被误导。

## 三、改进方案

### 1. 经济重做（A1–A6，B1）
1. **金额单位**：1 点现金 = ¥100 万，统一显示为「¥2,900 万 / ¥2.4 亿」。
2. **真实成本**：部件成本按真实 BOM 量级重标（顶级芯片约 ¥1,000+，旗舰整机 BOM ¥3,000+，入门机 ¥1,000 左右），另计渠道与营销费用（约售价的 15%）。顶级芯片 + ¥1,999 将是亏本买卖。
3. **销量对品质敏感 + 补货**：需求对媒体分、口碑、惊艳度更敏感；首批卖断货的需求不再浪费，变成之后几个月的**追加生产与补货**（按单台毛利入账）。爆款真正赚大钱。
4. **高价也能爆**：惊艳度越高，用户对价格越不敏感（苹果式）；平价和高端各有市场。
5. **成本同步放大**：工资、扩建、部门、流片、事件按新量级重标，保证经营压力还在。
6. **账本**：每笔现金变动记账；年终有「财报」分项（销售、补货、旧款、工资、研发投入、事件…），HUD 现金可点开看最近流水。

### 2. 用意外事件制造难度（A6，开罗式）
1. **行业大事件**（每代开局按概率出现，需要应对）：芯片断供/禁运、存储涨价、专利诉讼（赚得越多赔得越多）、关税、竞品爆款、网红带货等，带持续时间。
2. **堆料的物理代价**：顶级芯片 + 薄机身 + 无散热 → 「发热门」；便宜代工 + 大电池 → 「电池鼓包召回」。无脑堆性能会被事件打脸。

### 3. 规则说明（C1–C3）
1. **定位卡**：每个定位写清人群和用户期待（例：旗舰 = 性能、影像、续航、系统都要强；极简 = 小巧、颜值、够用），显示期待的研发配比。
2. **卖点说明 + 物理提示**：每个卖点有一句话解释和兑现条件；「极致轻薄」提示与大电池/大底三摄冲突（来自厚度，而非硬规定）。
3. **术语**：补充「流片」「性价比刺客」等解释；卫星天线等概念件改成能看懂的说明。

### 4. 设计台专业度（B2–B6，B8，D1–D2）
1. 「机械快门键」→「相机控制键」（按压拍照、轻滑变焦，海外版兼作 AI 键）。
2. **材质子类**：金属 → 铝合金 / 不锈钢 / 钛合金；素皮 → 纤维素皮 / 真皮。各自成本、重量、散热（影响续航上限）、质感不同。
3. **屏幕开孔形态移到「配置」**并标成本；外观页只留不花钱的项。
4. **创新页分两区**：「实用功能」（耳机孔、红外、存储卡、IP68…）与「前沿创新」。
5. **拼色**：增加左右拼色、斜切、镜头区异色。
6. **镜头布局**：少摄像头时布局要合理。
7. **光照**：浅色机身不再发灰。

### 5. 评论语境（B7）
评论结合价格与芯片档位：低价 + 高端芯片 → 「这价格还给 Pro 芯片？真香」，而不是「够用吗」。

### 6. 音乐（E1）
音乐与音效分开开关；音乐音量降低。

## 五、追加反馈（同一轮）

| # | 原话（节选） | 问题本质 |
|---|---|---|
| F1 | 「开发完全一模一样的手机，照样赚钱，也没降热度」 | 没有审美疲劳：重复上一代不受惩罚 |
| F2 | 「赚钱是一次性的…手机有周期性，周期性本身就是很核心的东西」 | 缺少产品生命周期：销量只在首月结算 |

方案：
1. **生命周期**：每台机型在售约 12 个月，经历「首发爬坡 → 热销 → 成熟 → 衰退 → 退市」。口碑好会越卖越多，竞品同定位发新机会分走销量，自家下一代会蚕食旧款。研发期间每月结算、每月可见；可随时降价续命（首发 3 个月内降价会背刺老用户）。
2. **审美疲劳**：新机与上一代的相似度（配置、概念件、配色造型、芯片代）越高，媒体分、口碑、热度和销量越低；设计台实时显示相似度。

## 核对结果

> 验证方式：① `npm run build` 通过；② 无头浏览器从开局玩到第 2 代（企划 → 设计 → 供应链 → 研发 → 量产 → 定价 → 发布会 → 评分 → 战报 → 规划下一代 → 行业大事件），全程无报错，关键页面截图核对；③ 用游戏逻辑批量模拟 3 年 × 50 局 × 9 种策略核对数值。

| # | 问题 | 结果 | 怎么做到的 / 证据 |
|---|---|---|---|
| A1 | 金额像小卖部 | ✅ | 1 点 = ¥100 万，统一显示「¥5.2 亿 / ¥9,600 万」（HUD、战报、财报、按钮、事件） |

### 遗留 / 下一步
- **镜头模组造型与能力绑定**（B5）：✅ 已补齐（见 `docs/QUALITY_BAR.md`）。模组移到「配置」、有成本，方形/圆形大模组可放潜望与一英寸大底；竖排胶囊/悬浮独立硬塞会减半影像加成并提示。旧文「暂未做」作废。
- **平价路线偏难**：模拟里平价 + 自研芯片能活下来（约 ¥10 亿），但明显弱于主流和旗舰；是否要再给平价路线一些专属优势（如出货量带来的供应链折扣），建议再试玩后决定。
- **后期现金很多**：玩得好时三年能到 ¥80–100 亿，后期缺少大额花钱的地方（如收购、自建工厂、海外市场），可作为下一阶段内容。
