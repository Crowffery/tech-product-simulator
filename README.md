# 留学模拟器（Study Abroad Simulator）

> **一句话定位**：回合制人生模拟 + 事件卡牌 + 轻策略资源分配——在有限申请季里经营多维成长与信息不对称，把「档案包」投向目标院校，体验真实申请压力与人生选择，而不是刷分答题。

## 仓库用途

本仓库存放《留学模拟器》的**游戏设计文档与讨论纪要**，供产品/玩法讨论与后续原型迭代。  
**当前阶段：设计讨论中**——尚无可运行游戏代码；先对齐愿景、核心循环与 MVP 边界。
