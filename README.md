# 科技公司模拟器（Tech Product Simulator）

> **一句话定位**：轻松开罗式月度经营——组有梗的团队、少数模块槽研发电子产品、用供应商档位+事件卡过供应链、办爽快发布会、看媒体分与月销量；把产品从概念做到货架，不是硬核 ERP。

> 📝 **仓库沿革**：原「留学模拟器」方向已废弃，本仓库已转向科技公司 / 电子产品主题（`tech-product-simulator`）。
